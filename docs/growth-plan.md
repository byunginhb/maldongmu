## 2. 하지 않을 것 (지금은)
- iOS 앱: 다운로드 2배 잠재력은 있지만 Apple 심사·연 13만원·WebView 앱 거절 리스크. 안드로이드에서 D1 20% 넘긴 뒤.
- 웹 UI 전면 다국어화: 해외 유입이 실제로 잡히기 전엔 보류. 대신 등록정보와 페르소나 답변 언어(이미 됨)로 테스트.
- 대규모 광고: 활성화·재방문 지표 없이 집행 금지.
- 게이미피케이션 확장(레벨·포인트): DESIGN.md 원칙과 충돌, 유지비 큼.

## 3. 측정 지표 (어드민 퍼널 카드 + Play Console)
- 유입: 신규 게스트/일, 스토어 설치/일, 등록정보 전환율(방문→설치), 유입 경로(UTM/referrer/앱)
- 활성화: 첫 메시지 전환율(목표 35%), 첫 메시지까지 시간(목표 <30초)
- 재방문: D1/D7 재방문율(목표 20%/8%), 푸시 오픈율
- 공유: 카드 공유 수, 공유 링크 유입 수, 공유→첫 메시지 전환
- 품질: 평점, 리뷰 수, 신고 수, ANR/크래시 0
