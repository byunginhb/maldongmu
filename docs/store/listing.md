## 6. 콘텐츠 등급 설문 (IARC) 답안 가이드

욕쟁이 할매의 '정겨운 욕/타박' 때문에 **가벼운 비속어**가 있으므로 정직하게 답하세요.

- 폭력: 없음
- 성적 콘텐츠: 없음 (시스템 프롬프트가 성적 대화를 거절)
- 비속어 / 저속한 유머: **예 — 가벼운 수준** (지역 사투리 타박, 모욕적이지 않은 정겨운 욕)
- 약물/도박: 없음
- 사용자 간 상호작용/사용자 생성 콘텐츠: **예** (AI와의 자유 대화, 사용자가 임의 텍스트 입력)
- 예상 등급: **만 12세 이상** (콘텐츠에 따라 IARC가 자동 산정)

## 7. 데이터 안전(Data Safety) 폼 답안 가이드

실제 서버가 저장/전송하는 데이터 기준 (apps/server DB + OpenRouter 전송).

**수집·전송하는 데이터**
| 데이터 | 수집? | 목적 | 제3자 공유 |
|---|---|---|---|
| 이메일 주소 | 예 (구글/카카오 로그인 시) | 계정 식별 | 아니오 |
| 이름/닉네임 | 예 (OAuth 프로필) | 계정 표시 | 아니오 |
| 앱 내 메시지(대화 내용) | 예 | 대화 기능 제공, AI 응답 생성 | **예 — LLM 제공자(OpenRouter)로 전송** |
| 앱 활동/사용 이벤트 | 예 | 통계·서비스 개선 | 아니오 |

**폼 체크포인트**
- "이 앱이 데이터를 수집하거나 공유합니까?" → **예**
- 전송 중 암호화 → **예** (HTTPS/TLS)
- 사용자가 데이터 삭제를 요청할 수 있나요 → **예** (계정/대화 삭제 지원 여부에 맞게)
- 대화 내용은 AI 응답 생성을 위해 제3자(OpenRouter)에 전송됨을 반드시 명시.
- 위치·연락처·금융정보·사진 → 수집 안 함.

> ✅ 개인정보처리방침(https://www.maldongmu.app/privacy)에 이미 명시돼 있음
> (3항 "대화 내용의 처리", 5항 "제3자 제공"에서 OpenRouter 전송을 안내). 데이터 안전 폼과 일치.
