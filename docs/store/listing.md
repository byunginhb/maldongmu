## 0. ASO 원칙 (2026-09-15 적용)

Play 스토어엔 키워드 필드가 없다 — **제목 > 간단한 설명 > 자세한 설명** 순으로 색인 가중치가 크다.
- 제목(30자): 브랜드 + 검색량 높은 키워드 2~3개. ko `AI`, `가상 연애`, `욕쟁이 할매`, `대화` / en `AI`, `Korean`, `Dating`
- 간단한 설명(80자): 카테고리 키워드를 자연어로 — ko `AI 친구`, `소개팅 시뮬레이션`, `페르소나` / en `virtual dating`, `AI personas`, `your language`
- 자세한 설명: 첫 3줄이 "더보기" 전에 노출 → 핵심 키워드를 첫 문단에. 끝에 "이런 분께" 절로 롱테일(외로울 때, 심심할 때, 연애 대화 연습, 한국어 연습)
- 해외: 페르소나가 사용자 언어로 답하는 점 + "한국어 연습"을 훅으로. UI가 한국어인 점은 정직하게 명시(리뷰 방어)
- **기본 언어 = en-US**: 지원 외 언어 기기엔 영어 등록정보가 보인다. 한국 기기는 ko-KR, 일본 ja-JP, 중화권 zh-TW/zh-HK/zh-CN
- 콘솔에서만 되는 것: 카테고리(엔터테인먼트 유지), 태그(`가상 연애`, `연애 시뮬레이션`, `AI 채팅`), 스토어 등록정보 실험(A/B)

## 6. 콘텐츠 등급 설문 (IARC) 답안 가이드

욕쟁이 할매의 '정겨운 욕/타박' 때문에 **가벼운 비속어**가 있고, 가상 연애는 **연애 감정 묘사**가 있으므로 정직하게 답하세요.

- 폭력: 없음
- 성적 콘텐츠: **없음** (가상 연애 프롬프트가 성적 묘사·노골적 신체 접촉을 금지. "손을 잡을까 말까" 수준의 설렘까지만)
- 비속어 / 저속한 유머: **예 — 가벼운 수준** (지역 사투리 타박, 모욕적이지 않은 정겨운 욕)
- 약물/도박: 없음
- 사용자 간 상호작용/사용자 생성 콘텐츠: **예** (AI와의 자유 대화, 사용자가 임의 텍스트 입력)
- 예상 등급: **만 12세 이상** (콘텐츠에 따라 IARC가 자동 산정)

> v1.1.0에서 설문 답은 v1.0.0과 동일. 콘솔이 "앱 콘텐츠 변경으로 설문 재검토"를 요구하면 위 답으로 다시 제출.

## 7. 데이터 안전(Data Safety) 폼 답안 가이드

실제 서버가 저장/전송하는 데이터 기준 (apps/server DB + OpenRouter 전송). **v1.1.0 변경 없음.**

**수집·전송하는 데이터**
| 데이터 | 수집? | 목적 | 제3자 공유 |
|---|---|---|---|
| 이메일 주소 | 예 (구글/카카오 로그인 시) | 계정 식별 | 아니오 |
| 이름/닉네임 | 예 (OAuth 프로필) | 계정 표시 | 아니오 |
| 앱 내 메시지(대화 내용) | 예 | 대화 기능 제공, AI 응답 생성, 호감도 추정 | **예 — LLM 제공자(OpenRouter)로 전송** |
| 앱 활동/사용 이벤트 | 예 | 통계·서비스 개선 | 아니오 |

**폼 체크포인트**
- "이 앱이 데이터를 수집하거나 공유합니까?" → **예**
- 전송 중 암호화 → **예** (HTTPS/TLS)
- 사용자가 데이터 삭제를 요청할 수 있나요 → **예** (https://www.maldongmu.app/account/delete)
- 대화 내용은 AI 응답 생성을 위해 제3자(OpenRouter)에 전송됨을 반드시 명시.
- 위치·연락처·금융정보·사진 → 수집 안 함.

> ✅ 개인정보처리방침(https://www.maldongmu.app/privacy)에 이미 명시돼 있음
> (3항 "대화 내용의 처리", 5항 "제3자 제공"에서 OpenRouter 전송을 안내). 데이터 안전 폼과 일치.
