# 홈 밸런스 게임

목표: 처음 방문한 사람이 상대를 고르거나 첫 문장을 입력하지 않고 한 번의 선택으로 대화를 시작한다.

인사말 예시는 대화 동기가 약하고, 성격 테스트는 결과까지 여러 단계를 요구한다. 대신 두 가지 중 하나를 고르는 밸런스 게임을 홈 헤더 바로 아래에 둔다. 이 방향과 질문은 구현 담당이 결정했다.

- 가벼운 일상·관계·상상 질문 5개. `다른 질문`으로 순환한다.
- 답을 누르면 질문, 두 선택지, 내 선택과 상대에게 묻는 문장을 기존 일반 대화에 한 번 전송한다. AI가 자신의 관점으로 답한 뒤 자유롭게 이어간다.
- 홈의 첫 추천 이웃을 보여주고 연결한다. 추천이 없으면 기존 랜덤 API를 사용한다.
- 자동 전송을 선택지 아래에 안내한다. 처리 중에는 모든 조작을 잠그고, 오류 시 다시 시도할 수 있다. 기존 로그인과 대화 한도를 따른다.
- 한국어·영어·일본어 UI와 시작 문장을 지원한다. 기존 초안 전달·중복 소비 방지·SSE 경로를 재사용한다.
- 기존 첫 문장 예시 영역을 대체한다. 새로운 서버 API, DB 변경, 모델 선호도 판정, 투표 수치는 추가하지 않는다.

구현 위치: `apps/web/components/HomeBalanceGame.tsx`, `apps/web/lib/balance-game.ts`. 질문·선택지는 후자에서 관리하고 번역은 `apps/web/lib/i18n.ts`에서 관리한다.

검증: `apps/web`에서 `pnpm exec node --test test/*.test.cjs`, 저장소 루트에서 `pnpm build`. 질문·선택지·선택 결과를 담은 메시지 생성, 세 언어 번역, 기존 일회성 초안 전달을 회귀 검사한다. UI와 배포 검증 결과는 작업 완료 보고에 기록한다. 이용자의 실제 대화 시작률 개선은 출시 후 관찰해야 한다.

2026-10-25 로컬 검증: 웹 44개·서버 27개 테스트 통과. 독립 코드 리뷰 통과. 모의 API를 사용하는 독립 브라우저 QA 23개 통과: 3개 언어 × 4개 화면 폭, 양쪽 선택의 정확한 1회 전송, 새로고침 재전송 방지, 40회 연속 클릭, 오류 재시도·로그인·랜덤 폴백, 키보드·포커스·reduced motion. 이 결과는 실제 모델 응답이나 운영 배포 검증을 대신하지 않는다.
