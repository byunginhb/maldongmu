# 홈과 이웃 수첩 순차 등장 변경안

계획: delivery-79990deb7616b281fd4eabd37c6eb131.
기준 revision: a4e49b1e2a3f51c11a6f94abaf5ce2d75b6968d2.

도구가 비활성화된 호출에서 작성한 9파일 변경 제안이다. 파일 적용·검사·리뷰·QA·병합·배포는 실행하지 않았다. PM 의견은 착수 범위로만 반영했다.

## 제안 동작

TodayFriends 버튼, 홈의 실제 오늘의 이웃·요즘 인기 목록, 데이터가 있는 /me 이웃 수첩에 RevealList를 사용한다. 스켈레톤과 오류·빈 상태, 셋이서 수다·가상 연애 섹션은 그대로 둔다. SSR에서는 내용을 표시하며, 마운트 후 observer 준비에 성공했을 때만 대기 상태를 적용한다. IntersectionObserver가 없거나 생성·관찰에 실패하면 내용을 표시한다. 각 목록은 observer 하나를 사용하고 최초 교차 직후와 언마운트 시 해제한다. ref로 재스크롤·일반 리렌더에서 재생을 막는다.

등장은 레이아웃을 유지하는 별도 래퍼에서 transform·opacity로 실행한다. 60ms 간격, 최대 360ms 지연과 300ms 등장으로 총 660ms 이내다. 실제 버튼·링크의 hover·active transform과 분리하고 등장 애니메이션은 종료 상태를 붙잡지 않는다. 키보드 포커스가 들어온 래퍼는 대기와 등장을 즉시 해제한다. 목록과 래퍼는 overflow를 자르지 않는다. 실제 대상은 최소 44×44px와 focus-visible 외곽선을 갖는다. hover는 hover 가능 기기에만 적용한다.

모션 줄이기에서는 목록·래퍼·실제 항목·기존 홈 등장에 animation·transition·transform을 해제한다. 기존 card·notebook active 반응도 같은 대상에서 해제된다. 새 그림자·그라데이션·coral 강조·의존성·반복 타이머를 추가하지 않는다. 기존 브랜드 토큰과 그리드를 유지한다.

PersonaCard test id와 조작 반응은 해당 컴포넌트를 쓰는 검색 등에도 적용된다. 순차 등장은 RevealList로 감싼 승인된 목록에만 적용된다. 온보딩·초안 전달·채팅·Avatar·번역·API·인증·게스트 한도는 수정하지 않는다.

## 예정된 검증과 인계

실행기는 기준 SHA와 각 preimage SHA-256, 최신 main·기존 변경을 확인하고 각 before가 정확히 한 번 존재하며 치환이 겹치지 않는 경우에만 적용한다. 새 순수 테스트는 설치된 TypeScript로 지연 모듈만 메모리에서 변환해 정상 순서·음수·NaN·무한대·큰 값·소수와 총 시간 상한을 검사한다. 등록된 unit-tests·typecheck·production-build는 모두 미실행이다.

적용 후 고정 커밋에서 등록 검사와 독립 리뷰를 받아야 한다. 독립 QA는 고정 preview의 360·1280px 홈과 데이터가 있는 /me에서 최초 1회 등장, 재스크롤·리렌더, observer 해제, 등장 중 포커스, 모든 새 대상의 크기·외곽선, hover·active와 등장 충돌, reduced-motion 실제 조작 상태, 가로 넘침·겹침·높이 보존을 확인해야 한다. /me 데이터가 비면 환경 문제로 기록하고 통과 처리하지 않는다.

기존 baseline과 별개로 taskAcceptance 단언을 실행하고 온보딩 예시 3개의 정확한 문장 1회 클릭 자동 전송을 회귀 확인해야 한다. 모의 backend 쓰기와 목록 결과는 실제 API·모델·DB 검증이 아니다. 고정 커밋의 검사·독립 리뷰·QA 후 최신 main 재확인과 통합, Vercel production 배포 SHA·운영 화면 확인이 남는다. 새 변경은 영향받는 검증을 무효화한다. 이 제안은 성능·메모리 실측이나 릴리스 완료 증거가 아니다.
