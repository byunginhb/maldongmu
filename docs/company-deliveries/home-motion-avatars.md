# 홈 모션과 사진 아바타 확장

2026-10-22. 기존 회사 직원의 미반영 작업을 CEO의 직접 마무리 요청으로 인계했다. 기준 main: adf406a09a342a5de6fa099118e8ee7a182d1217.

## 변경

- 헤더·온보딩·만남 영역에 짧은 등장 모션, 헤더 사진 묶음에 작은 움직임을 적용한다. 모션 줄이기 설정에서는 새 모션을 끈다. 기존 한 번 누르기/문장 전달·키보드 포커스·로딩 중 비활성 동작은 유지한다.
- 기존 WebP 사진48장을 보존하고, 보관된 추가 PNG48장을 재사용해 총96개 경로를 사용한다. 신규 이미지 생성이나 변환은 없다.
- 기존 성별·연령·uuid 키와 기존 사진 경로는 유지한다. 별도 uuid 해시 비트로 같은 그룹의 기존/추가 사진 중 하나를 안정적으로 선택한다. 사진 중복 가능성을 낮추며, 사람마다 고유한 사진을 보장하지는 않는다.

## 실제 이미지 그룹 연결

추가 파일은 **여성용001–024, 남성용025–048** 순서다. 앞선 구현 제안이 남성용 그룹에001–024를 연결한 문제를 마무리 과정에서 정정했다. 각 그룹의 연령 묶음은20·30·50·70 순서이며 묶음당6장이다. 파일은 public/company-generated/4914e797-98fe-4f77-9812-a5adfc7ab684/ 아래 보관한다.

| 그룹 | 추가 사진 번호 |
|---|---|
| 여성20 /30 /50 /70 | 001–006 /007–012 /013–018 /019–024 |
| 남성20 /30 /50 /70 | 025–030 /031–036 /037–042 /043–048 |

전체 추가 파일은768×768 PNG48개,49,700,806바이트다. 기존 사진과 추가 사진은 시각적으로 비교했으며 신원 동일성이나 완전한 비중복을 보증하는 검사가 아니다.

## 로딩·검증

Avatar는 기본lazy, 홈 헤더5장만eager이며 width/height·async decode를 유지한다. 실제 HERO_SEEDS에 따라 선택되는5장의 파일 합계는2,129,665바이트다(추가020·040 +기존3장). 이는 파일 크기 합계이며 실제 네트워크 전송량이나 LCP·CLS 측정은 아니다.

새 catalog의 그룹 연결·기존 경로 보존·결정적 선택·표본 도달/분포·PNG 무결성과 기존 온보딩/채팅 회귀를 포함한 단위30개가 통과했다. 타입·빌드·독립 리뷰와 핵심 브라우저 동작 및 실제 배포 확인 결과는 이 변경의 PR과 회사 운영 보고서에 기록한다. 로컬 모의 API 동작은 실제 채팅 모델/API 검증과 구분한다.

서버·인증·게스트 한도·기존 v1 사진·의존성/lockfile은 변경하지 않는다. 배포는 GitHub main 병합에 연결된 기존 Vercel 자동 배포를 사용한다.
